# Nola PRD 中文版

## 产品摘要

Nola | 诺拉 是一款 ADHD 友好型任务管理软件。它不是高压效率看板，而是一个安静的陪伴者，帮助用户捕捉、开始、回到并轻轻整理任务。

一句话承诺：

> Nola，不催你，只轻轻帮你开始。

## 目标用户

| 用户 | 需求 | 产品回应 |
| --- | --- | --- |
| ADHD 用户或执行功能困难用户 | 在不被压垮的情况下开始任务 | 很小的下一步、低压提示、随机启动 |
| 容易快速忘记想法和任务的用户 | 先捕捉，再整理 | 灵感箱与快速记录 |
| 抗拒僵硬效率系统的用户 | 允许恢复和中断 | 宽容的任务状态和温柔文案 |
| 桌面优先用户 | 需要更大的规划空间 | Windows/macOS MVP，包含日历、多级任务和本地数据 |

## 核心问题

许多任务系统默认用户能够平静地计划、排序和执行。但 ADHD 用户往往在这之前就需要帮助：捕捉散乱想法、降低任务摩擦、选择一个很小的下一步，并在中断后无负担地回来。

## 产品原则

- 不因未完成任务羞辱用户。
- 让开始比完美计划更容易。
- 用平静结构替代密集效率机制。
- 让任务状态可见，但不带惩罚感。
- 同时支持结构化任务和混乱灵感。

## 桌面端 MVP 页面集合

第一阶段桌面端 MVP 应使用一组少量、平静、可预测的页面。以下页面是 BL-002 批准的基线，供后续实施计划使用。

| 页面 | 用户结果 | 主要元素 | MVP 不包含 |
| --- | --- | --- | --- |
| Today | 在不过载的情况下看到现在可以开始什么 | 温柔问候、今日重点列表、低能量区域、随机启动入口、快速捕捉 | 密集分析、效率评分 |
| Tasks | 整理结构化工作 | 任务列表、嵌套子任务、状态、下一步、能量等级、项目分组 | 复杂看板、团队指派、时间追踪 |
| Inbox | 先捕捉，再整理 | 快速灵感捕捉、未处理条目、转为任务、归档 | AI 自动分类、外部集成 |
| Calendar | 按日期定位 | 月历视图、已排期任务、提醒标记、今日高亮 | 完整日历同步、会议管理 |
| Reminders | 管理本地提醒 | 提醒列表、创建固定提醒、编辑提醒、忽略状态 | 跨设备提醒、云端调度 |
| Random Start | 获得一个温柔的开始建议 | 一个建议任务、原因、小下一步、跳过选项、低能量筛选 | 游戏化、连续打卡压力 |
| Settings | 调整舒适度和本地行为 | 低刺激偏好、备份/导出入口、本地数据说明 | 账号、计费、云同步 |

## 桌面端 MVP 用户流程

### Today 流程

1. 用户打开 Nola。
2. Nola 展示平静的 Today 页面和简短重点列表。
3. 用户可以选择一个任务、捕捉新条目，或请求随机启动。
4. 如果用户处于低能量状态，页面优先展示更小的任务或下一步。

验收：

- 用户可以在 Today 页面中识别一个可能的下一步。
- 页面不要求用户先完成复杂优先级排序。

### Tasks 流程

1. 用户打开 Tasks 页面。
2. 用户创建带标题和可选下一步的任务。
3. 用户可以添加子任务、标记状态、设置能量等级或分配项目。
4. 用户稍后回来时，仍能看到任务上下文。

验收：

- 任务可以是简单条目，也可以是多步骤条目。
- 每个任务都可以携带一个很小的下一步。

### Inbox 流程

1. 用户快速捕捉想法，不需要先分类。
2. 条目以未处理状态出现在 Inbox。
3. 用户之后可以把它转为任务、留在 Inbox 或归档。

验收：

- 捕捉应比完整创建任务更快。
- Inbox 支持混乱想法，不强迫结构化。

### Calendar 流程

1. 用户打开 Calendar，按日期定位。
2. 用户看到已排期任务和提醒标记。
3. 用户可以选择日期查看当天计划。

验收：

- Calendar 帮助定位，而不是制造压力看板。
- 不要求完整外部日历同步。

### Reminders 流程

1. 用户为任务或灵感条目创建固定本地提醒。
2. Nola 本地保存提醒规则。
3. 用户可以编辑或忽略提醒。

验收：

- 提醒行为本地优先。
- 提醒文案应像轻提醒，而不是警报。

### Random Start 流程

1. 用户从 Today 或 Tasks 点击 Random Start。
2. Nola 建议一个可开始任务或下一步。
3. 用户可以开始、跳过，或请求另一个建议。
4. 低能量模式优先选择小任务。

验收：

- 建议被表达为可选支持。
- 用户跳过时不会受到惩罚。

第一阶段范围外：

- 账号系统

- 跨设备提醒

## MVP 验收标准

桌面端 MVP 在以下条件满足时可接受：

- 用户可以快速捕捉任务或想法。
- 用户可以在不过载的视觉环境中看到今日重点。
- 用户可以把任务拆成更小步骤。
- 用户可以存储和回看灵感箱条目。
- 用户可以创建固定提醒。
- 用户可以让 Nola 选择一个温柔的开始点。
- 数据可以在本地 SQLite 中持久保存。
- 界面符合 Nola 设计原则。
