# Nola PRD 中文版

## 产品摘要

Nola | 诺拉 是一款 ADHD 友好型任务管理软件。它不是高压效率看板，而是一个安静的陪伴者，帮助用户捕捉、开始、回到并轻轻整理任务。

一句话承诺：

> Nola，不催你，只轻轻帮你开始。

## 目标用户

| 用户 | 需求 | 产品回应 |
| --- | --- | --- |
| ADHD 用户或执行功能困难用户 | 在不被压垮的情况下开始任务 | 很小的下一步、低压提示、随机启动 |
| 容易快速忘记想法和任务的用户 | 先捕捉，再整理 | 灵感箱与快速记录 |
| 抗拒僵硬效率系统的用户 | 允许恢复和中断 | 宽容的任务状态和温柔文案 |
| 桌面优先用户 | 需要更大的规划空间 | Windows/macOS MVP，包含日历、多级任务和本地数据 |

## 核心问题

许多任务系统默认用户能够平静地计划、排序和执行。但 ADHD 用户往往在这之前就需要帮助：捕捉散乱想法、降低任务摩擦、选择一个很小的下一步，并在中断后无负担地回来。

## 产品原则

- 不因未完成任务羞辱用户。
- 让开始比完美计划更容易。
- 用平静结构替代密集效率机制。
- 让任务状态可见，但不带惩罚感。
- 同时支持结构化任务和混乱灵感。

## 第一阶段：桌面端 MVP 范围

平台：

- Windows
- macOS

范围内：

- 今日首页
- 多级任务管理
- 灵感箱
- 日历或月历视图
- 固定提醒
- 随机启动按钮
- 低能量任务模式
- 本地 SQLite 存储
- ADHD 友好视觉系统
- 本地备份或导出规划

第一阶段范围外：

- iOS 和 Android App
- 账号系统
- 云同步
- 跨设备提醒
- 订阅计费
- 完整 AI 任务拆解

## MVP 验收标准

桌面端 MVP 在以下条件满足时可接受：

- 用户可以快速捕捉任务或想法。
- 用户可以在不过载的视觉环境中看到今日重点。
- 用户可以把任务拆成更小步骤。
- 用户可以存储和回看灵感箱条目。
- 用户可以创建固定提醒。
- 用户可以让 Nola 选择一个温柔的开始点。
- 数据可以在本地 SQLite 中持久保存。
- 界面符合 Nola 设计原则。

## 成功指标

| 指标 | 意图 |
| --- | --- |
| 首个任务被捕捉 | 用户可以在低摩擦下开始 |
| 随机启动被使用 | 产品帮助克服启动困难 |
| 延迟后回到任务 | 产品支持无羞耻恢复 |
| 提醒被创建 | 用户愿意信任 Nola 的轻提醒 |
| 低能量任务被完成 | 产品帮助用户在能量不足时行动 |

## 开放问题

| 问题 | 重要性 | 状态 |
| --- | --- | --- |
| 最小有用的桌面 MVP 页面集合是什么？ | 决定第一轮实现范围 | 开放 |
| MVP 提醒是否仅本地？ | 影响架构和权限 | 默认：是 |
| AI 拆解现在规划接口，还是完全延后？ | 影响 package 边界 | 默认：仅规划接口，延后实现 |
