# Nola Roadmap 中文版

## 目的

本路线图用于保持 Nola 聚焦：桌面 MVP 第一，移动端第二，多端同步第三。

## 第一阶段：Windows/macOS 桌面端 MVP

目标：构建一个本地优先的桌面应用，帮助用户温柔地捕捉、开始和管理任务。

核心能力：

- Electron 桌面壳
- React + TypeScript 渲染层
- SQLite 本地存储
- Zustand 状态管理
- 今日首页
- 多级任务
- 灵感箱
- 日历或月历视图
- 固定提醒
- 随机启动
- 低能量任务模式
- ADHD 友好设计系统

退出标准：

- 桌面端 MVP 流程已实现并测试。
- 本地数据在重启后仍然存在。
- Windows 和 macOS 的提醒行为已验证。
- UI 通过低刺激和可访问性审查。
- 发布检查清单完成。

## 第二阶段：iOS/Android 移动端 MVP

目标：在桌面基础完成后，创建轻量移动端伴随应用。

核心能力：

- React Native + Expo App
- 共享 `packages/core`、`packages/types` 和 `packages/db-schema`
- 移动端 SQLite 存储
- 快速捕捉
- 今日任务
- 提醒
- 灵感箱
- 轻量日历
- 随机启动

退出标准：

- 移动端复用共享逻辑，但不强行共享 UI。
- 移动端提醒使用平台特定适配器。
- 本地数据模型与桌面端保持兼容。

## 第三阶段：多设备同步

目标：支持账号、云备份和跨设备连续性。

可能方案：

- Supabase：更快实现 MVP 同步
- Node.js + PostgreSQL：更适合长期自定义商业产品

核心能力：

- 账号系统
- 云数据库
- 设备管理
- 同步状态
- 冲突处理
- 自动备份
- 跨设备提醒
